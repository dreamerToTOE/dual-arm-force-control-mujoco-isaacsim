# Task05 — Cartesian Impedance Control

## 学习目标

让末端呈现“虚拟弹簧 + 阻尼器”的动态行为，并理解阻抗控制和刚性位置控制的区别。

## 核心思想

```text
W_cmd = Kx e_x + Dx e_v

tau = J^T W_cmd + compensation
```

其中位置和姿态误差要分别处理，第一版可先只做 3D 平移阻抗，再扩展 6D。

## 实现任务

1. 先做 TCP 三维平移阻抗；
2. 人为给末端一个外力/扰动，观察偏移与恢复；
3. 改变刚度 `Kx`，比较软/硬行为；
4. 加入阻尼 `Dx`，比较振荡；
5. 再扩展姿态阻抗。

## 验收

- TCP 能稳定收敛到目标附近；
- 外力撤去后稳定恢复；
- 输出位置误差、速度误差、commanded wrench、joint torque；
- 能解释为什么高刚度并不等于“更好的控制”。

## 常见错误

- 直接对四元数做普通减法；
- 平移刚度和旋转刚度单位混淆；
- 阻尼太小导致振荡，太大导致响应迟缓。
