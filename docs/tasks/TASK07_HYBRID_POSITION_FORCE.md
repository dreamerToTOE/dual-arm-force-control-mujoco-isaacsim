# Task07 — Hybrid Position / Force Control

## 学习目标

理解“某些方向控制位置、某些方向控制力”的混合控制思想。

典型场景：末端贴着平面滑动。

```text
切向 X/Y：位置/速度控制
法向 Z：力控制
```

## 实现任务

1. 明确任务 frame 与受约束方向；
2. 构造 position-selection 与 force-selection；
3. 法向保持指定接触力；
4. 切向跟踪一条直线或圆形轨迹；
5. 记录 TCP 轨迹与法向力。

## 验收

- 切向位置误差稳定；
- 法向力误差稳定；
- 两类控制目标不会明显互相打架；
- 能解释为什么同一受约束方向不能同时强制指定独立位置和独立力。

## 进入双臂前必须理解

Hybrid control 解决的是“任务方向解耦”，不是双臂力分配。Task08 才开始引入共同物体约束。
